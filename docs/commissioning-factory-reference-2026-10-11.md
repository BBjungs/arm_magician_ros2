# การใช้ข้อมูลโรงงานแทนการวัดซ้ำ

ตรวจที่ source HEAD `09bbb54` วันที่ 2026-10-11 ตามคำขอผู้ใช้ให้ใช้ข้อมูลโรงงาน
การตรวจครั้งนี้อ่านเอกสารและโค้ดเท่านั้น ไม่มีการส่ง Motion Goal หรือเปลี่ยน runtime

## หลักฐานที่ใช้ได้

- คู่มือ [Dobot Magician User Guide V1.7.0](evidence/official-dobot-magician/Dobot-Magician-User-Guide-V1.7.0.pdf)
  §3.3.2 หน้าเอกสาร 21–22 ระบุ origin ว่า “the center of the three motors
  (Rear Arm, Forearm, base)” และแกน X ไปด้านหน้า, Y ไปด้านซ้าย, Z ขึ้นบน
  ข้อความนี้ไม่ได้ระบุว่า origin อยู่บนผิวโต๊ะ และไม่ได้ให้ระยะจากผิวรองรับถึง origin
- [บันทึกหลักฐานโรงงานเดิม](evidence/official-dobot-magician/geometry-acquisition-report.md)
  ระบุ suction preset ของซอฟต์แวร์ผู้ผลิตเป็น `[59.7, 0, 0]` mm
  ค่านี้เป็น controller end-effector offset ไม่ใช่ระยะจาก origin ถึงปากหัวดูด
  จึงห้ามนำไปแทน TCP หรือเขียนทับพารามิเตอร์ controller โดยตรง
- บันทึกเดิมมี factory internal TF ของกล้อง serial `AY2A760003E`
  ใช้เป็นแหล่งข้อมูลภายในกล้องได้เมื่อยืนยัน identity/profile ตรงกัน
  แต่ไม่ใช่ transform ระหว่างแขนกับขายึดกล้อง
- บันทึกเดิมมีการวัดชุดติดตั้ง: tool → ปากหัวดูด `[0,0,-70]` mm
  และ tool → camera reference `[50,0,-35]` mm
  ใช้หลักฐานเดิมต่อได้เมื่อชุดติดตั้งยังตรงกัน ไม่จำเป็นต้องวัดซ้ำทุกมิติ
  camera reference ไม่เท่ากับ optical frame โดยอัตโนมัติ

## ค่าที่ยังหาแทนจากโรงงานไม่ได้ในการตรวจนี้

1. `table_surface_z_m`: URDF มี `link_base_length=0.131305` m แต่ยังไม่มี
   หลักฐานผูก datum ของค่านี้กับผิวรองรับจริงและ controller frame
   จึงยังไม่ใช้ทั้ง `0.0` หรือ `-0.131305` เป็นค่าที่ verified
   หากแบบโรงงานยืนยันความสูง origin เหนือผิวรองรับเป็น h และฐานวางตรงบนโต๊ะ
   โดยแกน Z ตั้งฉากกับโต๊ะ จึงคำนวณ table Z = -h ได้โดยไม่ต้องวัดความสูงใหม่
2. `free_volume_min_m/max_m`: เป็นขอบเขตพื้นที่ติดตั้งที่ไม่มีสิ่งกีดขวาง
   ไม่ใช่ขอบเขตระยะเอื้อมตามสเปก ตัวเลขโรงงานจึงยืนยันพื้นที่นี้ไม่ได้
3. ขอบเขตขายึด กล้อง หัวดูด สาย และท่อทั้งชุดตลอดเส้นทาง:
   ต้องอ้างอิงชุดติดตั้งจริงหรือ CAD ที่ตรงกับชุดนั้น รวมความคลาดเคลื่อน
   ไม่สามารถใช้สเปกหุ่นยนต์เปล่าแทนได้

ไม่เปลี่ยน verified flags หรือ safety thresholds จากการเลือกใช้แหล่งข้อมูลโรงงาน
ผลนี้เป็นการตรวจ provenance ไม่ใช่ผลทดสอบ commissioning
